# Avitus

Application de généalogie : construis ton arbre, tes fiches, tes récits et la carte de ta famille, sur ordinateur et sur téléphone, avec synchronisation entre tes appareils.

## Télécharger

Les installateurs sont dans la page **[Releases](../../releases/latest)** :

- **Windows** : `Avitus-…-Setup.exe` (installation) ou `Avitus-Windows-portable.zip` (sans installation).
- **Android** : `Avitus-….apk` (dans la version nommée « Avitus Android … »). Autorise l’installation d’applications hors Play Store quand Android le demande.

Les mises à jour se font ensuite depuis l’application (Paramètres › Mises à jour).

## Guide de démarrage

**[Télécharger le guide (PDF)](https://kaneis101.github.io/Avitus/Avitus-guide-demarrage.pdf)** : installer, créer l’arbre, explorer, partager. La présentation est sur [kaneis101.github.io/Avitus](https://kaneis101.github.io/Avitus/).

## Compte

Crée ton profil avec ton adresse e-mail, un pseudo et un mot de passe. Si tu oublies ton mot de passe, « Mot de passe oublié ? » t’envoie un e-mail avec un lien pour en choisir un nouveau.

## Intelligence artificielle (facultatif)

Les fonctions d’IA utilisent **ta propre clé** (Groq et/ou Gemini), à saisir dans Paramètres › Intelligence artificielle. Elle est chiffrée et rattachée à ton compte.

Ce dépôt ne contient que les installateurs ; le code source est privé.
